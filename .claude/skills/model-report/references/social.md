# social.md

One template. X only, Korean only, 280 characters extended as a thread, with the GitHub
link placed in a reply rather than the first post.

## The template

```
Post 1 (first post, ≤280 characters, Korean)
  - one line on the model
  - exactly one performance number
  - the demo media attached directly to this post

Post 2..N (thread, continued replies to post 1)
  - the architectural point, the limits, the usage-scope quote when one exists

Reply to post 1 (posted after the thread, not inside it)
  - the GitHub example link
```

The link goes in a reply, not the first post, because a link in the first post of a
thread measurably reduces that post's own reach on X. Everything the reader needs to
decide whether to click through — the model, the number, the media — is already in the
post they are looking at; the link is one tap away in the replies.

## Four required elements

| Element | Where | Rule |
|---|---|---|
| One line on the model | first post | states what it is, not a pitch |
| Exactly one performance number | first post | RTF, or "an hour in N minutes" — never a second number, and never the full table from the report |
| The demo media | first post | attached to the post directly |
| The GitHub example link | a reply to the first post | never the first post itself |

```
✗ Two performance numbers in the first post — for example RTF and peak video memory
  together.
→ One number only. RTF ("0.08×") or a plain-language equivalent ("an hour of audio in N
  minutes") — whichever reads faster in 280 characters.
Why: the post has one thing to say, not the whole report. A second number competes with
the first for the reader's five seconds of attention and both lose.
```

## The one prohibition

```
✗ The post reads as advice to deploy the model — "빠르고 정확해서 바로 프로덕션에 써도
  됩니다" or anything with that shape.
→ When `model-showcase`'s research step recorded a usage-scope restriction, the thread
  carries it — quoted or closely paraphrased, in one of the later posts, not the first —
  and the post stops short of recommending deployment itself.
Why: a 280-character first post has no room for the full usage-scope quote, but the
thread does. Giving shipping advice the model's own authors decline to give is the one
way this post can do real harm, and it costs nothing to avoid.
```

When the research table carries no usage-scope restriction at all, the thread needs no
disclaimer manufactured for one — silence in the research table is not itself a
restriction to invent language for.
