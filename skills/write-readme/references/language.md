## 기준 파일

README를 어떤 파일로 낼지, 어느 파일을 기준으로 나머지를 쓰는지, 모든 README를 어떻게 맞추는지 정한다. 섹션은 기준 파일에 먼저 쓰므로 섹션보다 이것을 먼저 정한다. 서비스와 같은 수준의 README를 두세 개 먼저 읽는다.

| 옆에 있는 것 | 기준 파일 |
| :---: | --- |
| 없다 | `README.ko.md` |
| 파일명, 언어 전환 줄, 섹션 순서가 모든 README에서 일치한다 | 그 README가 쓰는 파일, 그대로 따른다 |
| README끼리 어긋난다 | `README.ko.md` |

수준이 다른 README는 이 서비스의 관례가 아니다. 이웃 서비스끼리는 같은 수준이고 리포지터리(Repository) 루트(Root)는 아니다.

## 파일과 언어

| 파일 | 언어 |
| :---: | --- |
| `README.ko.md` | 한국어 |
| `README.md` | 영어 |
| `README.zh-cn.md` | 중국어 |

모든 README는 한 묶음이고 한 파일만 고치지 않는다. 모든 파일은 첫 줄에 같은 언어 전환 줄을 두고 실제로 있는 파일만 가리킨다.

```
[English](README.md) · [한국어](README.ko.md) · [中文](README.zh-cn.md)
```

번역본은 줄 단위로 옮기지 않고 같은 구조를 따라 그 언어로 다시 쓴다.

| 부분 | 번역 |
| :---: | --- |
| 산문, 표의 설명 열, 섹션 헤딩(Heading), 라이선스(License) 인용을 뺀 코드 블록(Code Block) 안의 주석, 도식 안의 텍스트 | ✓ |
| 식별자, 타입(Type) 이름, 파일 경로, 명령, 코드, 언어 태그, URL, 언어 전환 줄 | ✗ |
| 렌더(Render)한 성능표, 그 아래 노트, 측정 조건 블록 | ✗ 손으로 번역하지 않는다, 파일마다 `--language`로 따로 렌더해 출력 그대로 옮긴다 |
| 라이선스 인용 | ✗ 업스트림(Upstream) 원문 그대로 코드 블록에 두고 번역을 덧붙이지 않는다 |

## 맞추기

```bash
python -B "${CLAUDE_SKILL_DIR}/scripts/sync_check.py" <서비스 폴더> [기준 파일명]
```

기준 파일이 `README.ko.md`면 기준 파일명은 생략한다. 종료 코드(Exit Code) `1`은 구조 차이만 알리므로, `1`을 먼저 모두 해소하고 다시 돌린 뒤 `3`을 판정한다.

| 종료 코드 | 행동 |
| :---: | --- |
| `0` | 완료 |
| `1` | 짚은 섹션 헤딩을 기준 파일의 헤딩으로 바꾸고, 나머지 차이도 기준 파일에 맞춘 뒤 재실행 |
| `2` | 인자(Argument)와 파일 확인 |
| `3` | 차이마다 아래 표로 판정 |

| 차이 | 행동 |
| :---: | --- |
| 헤딩이나 번역된 구절을 담은 코드 스팬(Code Span) | 무시, 보고하지 않는다 |
| 주석이나 도식 안에서만 다른 줄(줄 끝 주석 포함) | 무시, 보고하지 않는다 |
| 언어별 문서 링크 | 무시, 보고하지 않는다 |
| 주석 밖의 식별자·명령·경로·옵션(코드와 주석이 함께 바뀐 줄 포함) | 기준 파일에 맞추고 재실행 |
| 번역인지 코드인지 불분명 | 코드로 취급 |

무시할 차이만 남으면 모든 README가 맞춰진 것이다.
